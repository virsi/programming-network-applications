# PRD: Система учета кешбэка «СберСтиль»

## 1. Общие сведения
Данный проект является реализацией Лабораторной работы №3 по курсу «Проектирование сетевых приложений». Приложение представляет собой двухстраничный веб-интерфейс для выбора категорий кешбэка, стилизованный под дизайн-систему банка **Сбер**.

**Тема:** Система учета кешбэка.  
**Вариант (согласно методичке):** №6 (Финансы).  
**Ключевой компонент:** Всплывающие сообщения (Toasts).

---

## 2. Цели и задачи
*   **Соответствие методичке:** Реализовать классовую архитектуру (`Page`, `Component`).
*   **Визуальное превосходство:** Использовать премиальный дизайн Сбера (цвета, тени, скругления).
*   **Функциональность:**
    *   Отображение списка категорий кешбэка на главной странице.
    *   Переход на страницу подробностей каждой категории.
    *   Механика «Активации» категории с визуальным подтверждением.

---

## 3. Функциональные требования

### 3.1. Главная страница (MainPage)
*   Грид-раскладка (Grid) из карточек категорий.
*   Каждая карточка (`ProductCardComponent`) содержит:
    *   Имя категории (например, «Рестораны»).
    *   Яркий бейдж с процентом кешбэка (например, «5%»).
    *   Качественное фоновое изображение/иконку.
    *   Кнопку «Активировать».

### 3.2. Страница продукта (ProductPage)
*   Подробное описание выбранной категории.
*   Изображение в высоком разрешении.
*   Кнопка «Назад» для возврата к списку.

### 3.3. Уведомления (Toasts)
*   При нажатии на кнопку активации в карточке, в верхней части экрана появляется Toast: *«Категория [Название] успешно активирована!»*.
*   Стиль Toast должен соответствовать мобильному приложению Сбера (зеленая иконка галочки, белый фон, мягкая тень).

---

## 4. Дизайн-система (Sber)
*   **Первичный цвет:** `#21a038` (Sber Green).
*   **Фон:** `#f0f7f2` (Light Mint).
*   **Скругления:** `28px` для карточек, `16px` для кнопок и инпутов.
*   **Шрифт:** Inter / Sans-serif.
*   **Интерактивность:** Плавные `hover` эффекты (увеличение карточки на 2%, подсвечивание кнопки).

---

## 5. Технический стек
*   **HTML5** (Семантическая верстка).
*   **Vanilla JS** (Классы, модули ES6).
*   **CSS3** (Flexbox/Grid, переменные).
*   **Bootstrap 5** (Основа для Toasts и сетки).

---

## 6. План реализации (Кратко)
1.  **Настройка стилей:** Доработка `style.css` для карточек и анимаций.
2.  **Компоненты:** Создание `ProductCardComponent` и `ToastComponent`.
3.  **Страницы:** Реализация `MainPage` с моковыми данными (Массив категорий).
4.  **Маршрутизация:** Логика переключения между страницами в `main.js`.
