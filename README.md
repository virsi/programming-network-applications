## 📌 Что было сделано

В этой ветке к статической вёрстке добавлена **полноценная логика**
калькулятора:

- Все 4 арифметические операции: `+`, `−`, `×`, `÷`.
- Унарные: смена знака `+/-`, процент `%`, очистка `C`.
- Десятичная точка с защитой от двойного ввода.
- Обработка с **клавиатуры** (включая русскую `с` для Clear).
- Защита от переполнения (≤ 10 цифр в дисплее).
- Корректное форматирование больших чисел через `toExponential`.
- Обработка деления на ноль (`Infinity` → «Ошибка»).
- Делегирование событий — один listener на всю клавиатуру.

## 🧠 Архитектура: машина состояний

Калькулятор реализован как **конечный автомат** с 4 переменными состояния:

| Переменная                | Тип         | Назначение                                            |
| ------------------------- | ----------- | ----------------------------------------------------- |
| `displayValue`            | `string`    | То, что прямо сейчас на экране                        |
| `firstOperand`            | `number?`   | Левый операнд (накопленный результат)                 |
| `operator`                | `string?`   | Текущий выбранный оператор (`+`, `−`, `×`, `÷`)       |
| `waitingForSecondOperand` | `boolean`   | Флаг «следующая цифра начнёт новый операнд»           |

### Граф переходов

```
         digit
   ┌──────────────┐
   ▼              │
 [INPUT_1] ──op──▶ [WAIT_2] ──digit──▶ [INPUT_2] ──=──▶ [RESULT]
   ▲                                                        │
   └────────────────────── digit ───────────────────────────┘
```

## 🔧 Поддерживаемые операции

| Кнопка / клавиша     | Что делает                                                | Реализация                       |
| -------------------- | --------------------------------------------------------- | -------------------------------- |
| `0–9`                | Ввод цифры                                                | `inputDigit(d)`                  |
| `.` / `,`            | Десятичная точка (только одна на число)                   | `inputDecimal('.')`              |
| `+ − × ÷`            | Бинарная операция; цепочки: `2+3+4` → `9`                 | `handleOperator(op)`             |
| `=` / `Enter`        | Финализация выражения                                     | `calculate(a, b, op)`            |
| `+/-`                | Смена знака текущего числа                                | `handleSign()`                   |
| `%`                  | Контекстный процент: от первого операнда или просто /100  | `handlePercent()`                |
| `C` / `Esc` / `Del`  | Полный сброс                                              | `resetCalculator()`              |
| `Backspace`          | Удалить последний символ                                  | `slice(0, -1)`                   |

## ⚙️ Обработка краевых случаев

| Кейс                                  | Поведение                                              |
| ------------------------------------- | ------------------------------------------------------ |
| `5 ÷ 0`                               | `Infinity` → форматтер показывает `Ошибка`             |
| Число длиннее 10 знаков               | Перевод в экспоненциальную запись `1.23e+12`           |
| Двойная точка `12.3.4`                | Вторая точка игнорируется                              |
| `5 + + 3`                             | Второй оператор перезаписывает первый                  |
| `0` как первая цифра при пустом вводе | Заменяется новой цифрой                                |
| Русская `с` (раскладка)               | Тоже работает как Clear                                |

## 🪜 Делегирование событий

Вместо навешивания 19 листенеров на каждую кнопку — один `click` на
контейнер `.keyboard`:

```js
keyboard.addEventListener('click', (event) => {
    const target = event.target;
    if (!target.matches('button')) return;

    switch (target.id) {
        case 'btn_op_clear':   resetCalculator(); break;
        case 'btn_op_equal':   /* финал */ break;
        default:
            if (target.classList.contains('digit'))   inputDigit(target.innerText);
            if (target.classList.contains('primary')) handleOperator(target.innerText);
    }
    updateDisplay();
});
```

**Плюсы:**
- ✅ Один listener вместо ~20 — меньше памяти.
- ✅ Динамически добавленные кнопки тоже сработают.
- ✅ Легче дебажить — вся логика в одном месте.

## ⌨️ Поддержка клавиатуры

Карта раскладки `keydown → действие`:

| Клавиша         | Маппинг                  |
| --------------- | ------------------------ |
| `0…9`           | `inputDigit`             |
| `+ - * /`       | `handleOperator('+/-/×/÷')` |
| `Enter`, `=`    | финализация              |
| `Esc`, `Del`, `C/c/С/с` | `resetCalculator` |
| `Backspace`     | удалить последний символ |
| `.`, `,`        | `inputDecimal('.')`      |

`event.preventDefault()` — чтобы браузер не пытался сделать что-то своё
(например, искать на странице по `/`).

## 📐 Алгоритм `formatNumber`

```js
function formatNumber(numStr) {
    const num = parseFloat(numStr);
    if (isNaN(num) || !isFinite(num)) return 'Ошибка';

    const str = String(num);
    if (str.length <= MAX_DIGITS) return str;          // помещается

    const expStr = num.toExponential(4);               // 1.2345e+12
    if (expStr.length <= MAX_DIGITS) return expStr;
    return num.toExponential(2);                       // запасной вариант
}
```

| Вход            | Выход (MAX = 10) |
| --------------- | ---------------- |
| `42`            | `42`             |
| `3.14159265`    | `3.14159265`     |
| `1234567890123` | `1.2346e+12`     |
| `Infinity`      | `Ошибка`         |
| `NaN`           | `Ошибка`         |
