# Лабораторная работа hw1 — Алгоритмы на JS + Three.js

> **Тема:** «Задачи на циклы, массивы, коллекции, объекты на JS» + интеграция функций
> в реальное веб-приложение «Sber Cashback».
> **Курс:** «Программирование сетевых приложений» (БМСТУ).

---

## 📌 Что было сделано

В рамках работы реализованы алгоритмические задачи из методички (`hw.md`)
и встроены в готовый интерфейс кешбэк-сервиса. Каждая функция имеет
прикладное применение в UI: подсчёт суммы транзакций, поиск максимальной
полосы кешбэк-дней, слияние конфигураций аккаунта и т.д.

Дополнительно:

- 🎨 Многостраничное SPA на чистом JS (без фреймворков) с роутингом через классы-страницы.
- 🧩 Компонентная архитектура (`components/`).
- 🪙 3D-сцена с монетой (Three.js + GLTFLoader + OrbitControls).
- 💾 Сохранение активированного процента в `localStorage`.
- 🔔 Toast-уведомления о статусе операции.
- 🖥️ **Все входные данные для алгоритмических задач вводятся пользователем
  через консоль (`prompt`)** в `utils/cashbackUtils.js`.

### Краткая теория

#### Задача 1.4 — сумма и произведение
Линейный обход массива за **O(n)** времени и **O(1)** дополнительной памяти.
Произведение инициализируется единицей (нейтральный элемент умножения),
сумма — нулём.

```js
let sum = 0, mult = 1;
for (const v of arr) { sum += v; mult *= v; }
```

#### Задача 1.9 — заполнение массива
Создание массива фиксированной длины и заполнение его одним значением.
Эквивалент `Array(count).fill(data)`, но реализован вручную для отработки циклов.

#### Задача 2.3 — максимальная подпоследовательность единиц
Классическая задача со «скользящим окном». Поддерживаем два счётчика:
текущая длина серии и максимальная встретившаяся длина.

| Тип цикла  | Сложность | Доп. память |
| ---------- | --------- | ----------- |
| `for…of`   | O(n)      | O(1)        |

#### Задача 3.1 — слияние объектов
Перебор полей всех объектов слева направо. Поле фиксируется только при
**первом** его появлении — последующие игнорируются. Это делает функцию
идеальной для системы «default → user → override» наоборот: первый
переданный объект имеет приоритет.

```js
mergeAccountConfigs(userConfig, defaults) // user wins
```

#### Бонус — `do…while`
Цикл с пост-условием: тело гарантированно выполнится хотя бы один раз.
Используется для имитации синхронной обработки транзакций.

## ▶️ Запуск

```bash
npm install
# любой статический сервер:
npx serve .
# или:
python3 -m http.server 5500
```

Затем открыть [http://localhost:5500](http://localhost:5500), кликнуть
по любой карточке кешбэка — браузер последовательно покажет 6 диалогов
`prompt()` для ввода входных данных задач.

> 💡 Если нажать **Отмена** или оставить поле пустым — будут
> использованы значения по умолчанию (см. `readCashbackInputsFromConsole`).
