## 📌 Что было сделано

Построен **многостраничный SPA** на ванильном JS — **без фреймворков**.
Никаких роутинговых библиотек: переключение страниц делается заменой
содержимого `#root`. Для стилей подключён Bootstrap 5 + кастомный CSS.

## 🧩 Компонентная архитектура

Каждый компонент — это класс с двумя обязательными методами:
`getHTML(data)` и `render(data, listener)`.

```
components/
├── product-card/index.js      — карточка категории на главной
├── product/index.js           — детальная панель товара
├── back-button/index.js       — кнопка «← Назад»
└── toast/index.js             — toast-уведомление
```

### Шаблон компонента

```js
export class ProductCardComponent {
    constructor(parent)            { this.parent = parent; }
    getHTML(data)                  { return `<div>…</div>`; }
    addListeners(data, listener)   { /* привязки событий */ }
    render(data, listener) {
        this.parent.insertAdjacentHTML('beforeend', this.getHTML(data));
        this.addListeners(data, listener);
    }
}
```

### Иерархия страниц

```
MainPage
└─ ProductCardComponent × 4

ProductPage
├─ BackButtonComponent
└─ ProductComponent
   └─ (на activate) → ToastComponent
```

| 4  | Одежда и обувь         | 20%         | `assets/fashion.png`  |

## 💾 Сохранение в `localStorage`

Активированные значения процента сохраняются под ключом
`cashbackPercents` в виде словаря `{id: percent}`:

```js
const saved = JSON.parse(localStorage.getItem('cashbackPercents') || '{}');
saved[id] = newPercent;
localStorage.setItem('cashbackPercents', JSON.stringify(saved));
```

Это значит, что **карточки на главной показывают актуальный процент**
даже после перезагрузки страницы — `ProductCardComponent.getPercent`
сначала смотрит в storage, потом fallback на дефолт.

## 🎨 Стили

| Технология        | Использование                                |
| ----------------- | -------------------------------------------- |
| Bootstrap 5       | Сетка `container-fluid`, утилиты `p-*`, `mb-*` |
| Кастомный CSS     | Бренд Сбера, hover-эффекты, тостеры          |
| Google Fonts      | Inter (400–700)                              |

Кастомные классы:
- `.cashback-card` — карточка с скруглением 16px и тенью.
- `.cashback-badge` — зелёный «лейбл» с процентом.
- `.btn-activate` — большая зелёная CTA-кнопка.
- `.sber-toast-container` — контейнер тостов в правом нижнем углу.
