> **Тема:** «Знакомство с HTML и CSS. Вёрстка статической страницы калькулятора»
> **Курс:** «Программирование сетевых приложений» (БМСТУ).
> **Стилистика:** в фирменном стиле Сбера (зелёные акценты, скругления, тени).

## 📌 Что было сделано

На этом этапе создан **полностью статический интерфейс** калькулятора кешбэка:
без логики, без JS-вычислений — только разметка и стили. Цель — отработать
семантическую вёрстку, CSS Grid/Flexbox, переменные CSS и адаптивные единицы.

| Подзадача                                | Файл              |
| ---------------------------------------- | ----------------- |

## 🎨 Дизайн-система

Сделана крошечная дизайн-система через CSS-переменные. Темная и светлая
темы переключаются изменением класса на `<body>`:

| Токен                   | Light                | Dark                 |
| ----------------------- | -------------------- | -------------------- |
| `--bg`                  | `#f5f7fa`            | `#0f1115`            |
| `--card`                | `#ffffff`            | `#1a1d24`            |
| `--text-primary`        | `#0f1115`            | `#f5f7fa`            |
| `--accent` *(Sber)*     | `#21a038`            | `#21a038`            |
| `--radius`              | `16px`               | `16px`               |

```css
.light-theme { --bg: #f5f7fa; --card: #fff; --text: #0f1115; }
.dark-theme  { --bg: #0f1115; --card: #1a1d24; --text: #f5f7fa; }
```

## 🧱 Структура клавиатуры

Кнопки калькулятора собраны в **CSS Grid 4×5**, кнопка `0` растянута на
две ячейки (`grid-column: span 2`), что соответствует классическому
дизайну iOS-калькулятора.

| Класс кнопки | Назначение           | Цвет           |
| ------------ | -------------------- | -------------- |
| `.digit`     | Цифры 0–9, точка     | белый/серый    |
| `.secondary` | `C`, `+/-`, `%`      | светло-серый   |
| `.primary`   | `+`, `−`, `×`, `÷`   | оранжевый      |
| `.execute`   | `=`                  | зелёный (Сбер) |

Каждая кнопка имеет уникальный `id` вида `btn_digit_5`, `btn_op_plus`,
`btn_op_equal` — это контракт, который позже подхватит JS-логика
в ветке `calc-implementation`.

## 📐 Семантическая разметка

```html
<main class="container">
  <section class="navigation-panel card">…</section>
  <section class="calculator-card card">
    <div id="result" class="display">0</div>
    <div class="keyboard">…</div>
  </section>
</main>
```

- `<main>` — единственная главная зона страницы.
- `<section>` — независимые блоки (навигация и калькулятор).
- `<a>` для ссылок между страницами вместо `<button onclick="location.href=…">`.

## 🌗 Переключение темы

Единственный JS на этой ветке — переключение темы. Состояние
сохраняется в `localStorage`, чтобы не сбрасываться при навигации.

```js
const saved = localStorage.getItem('theme') || 'light';
document.body.classList.add(saved + '-theme');

themeSelect.addEventListener('change', function () {
  document.body.className = '';
  document.body.classList.add(this.value + '-theme');
  localStorage.setItem('theme', this.value);
});
```
